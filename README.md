# 🚀 FutureTech Hub

### Learn. Build. Evolve.

**Laboratório digital de Engenharia de Software, tecnologia e aprendizagem prática.**

O **FutureTech Hub** é um projeto em desenvolvimento criado para transformar estudos em prática, projetos, experimentos, documentação e conhecimento compartilhado.

O projeto surgiu durante minha formação em **Engenharia de Software** e está sendo desenvolvido como uma plataforma tecnológica em evolução.

> **Aprender → Praticar → Construir → Documentar → Compartilhar → Evoluir**

---

## 🚧 Status

**Em desenvolvimento ativo**

A versão atual já possui:

- interface responsiva;
- React + Vite;
- design system próprio;
- animações e microinterações;
- acessibilidade;
- SEO básico;
- FutureTech Lab;
- FutureAI conceitual;
- deploy na Vercel.

A **V2 está em desenvolvimento**, com foco em nova identidade visual, logo, brand system, páginas internas, trilhas, projetos, laboratório e conteúdos.
