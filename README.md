## 📌 Sobre o projeto

O **FutureTech Hub** é um laboratório digital em desenvolvimento criado para transformar o processo de aprendizagem em Engenharia de Software em uma experiência prática, estruturada e compartilhável.

A proposta é reunir, em um único ecossistema:

- estudos técnicos;
- trilhas de aprendizagem;
- projetos práticos;
- experimentos;
- conteúdos;
- ferramentas;
- documentação;
- desenvolvimento de software;
- evolução profissional.

O projeto surgiu durante minha formação em **Engenharia de Software** e evolui junto com meus estudos e minha experiência prática em desenvolvimento.

Mais do que uma landing page, o FutureTech Hub está sendo desenvolvido como uma **plataforma tecnológica em evolução**, conectando conhecimento teórico, experimentação e construção prática.

> **Aprender → Praticar → Construir → Documentar → Compartilhar → Evoluir**

O FutureTech Hub é uma iniciativa da **Luara Digital**.

## 🏗️ Arquitetura

O frontend foi estruturado utilizando uma arquitetura componentizada, com separação entre conteúdo, interface, comportamento e estilos.

```text
futuretech-hub/
│
└── frontend/
    │
    ├── public/
    │   └── favicon.svg
    │
    ├── src/
    │   ├── components/
    │   ├── data/
    │   ├── sections/
    │   ├── styles/
    │   │   ├── tokens.css
    │   │   ├── base.css
    │   │   └── app.css
    │   │
    │   ├── App.jsx
    │   ├── main.jsx
    │   └── useReveal.js
    │
    ├── index.html
    ├── eslint.config.js
    ├── package.json
    └── vite.config.js


Organização

components/
Componentes reutilizáveis da interface.

sections/
Grandes blocos responsáveis pelas principais áreas da aplicação.

data/
Conteúdo editorial desacoplado da estrutura visual.

styles/
Tokens, estilos base, componentes visuais, responsividade e design system.

useReveal.js
Hook responsável pelo sistema reutilizável de animações acionadas durante o scroll.

✨ Motion Design

O projeto possui um sistema próprio de animações sem dependências externas específicas para motion.

Tecnologias utilizadas:

IntersectionObserver
+
CSS Animations
+
CSS Transitions

O useReveal.js identifica elementos que entram na viewport e aplica:

opacity;
pequenos deslocamentos verticais;
escala mínima;
stagger;
reveal de cards;
reveal de headings;
reveal de painéis;
entrada progressiva de elementos.

Após o elemento ser revelado, ele deixa de ser observado.

Isso reduz processamento contínuo desnecessário durante a navegação.

🧘 Reduced Motion

O projeto respeita a preferência:

@media (prefers-reduced-motion: reduce)

Quando essa configuração está ativa:

smooth scrolling é removido;
animações contínuas são desativadas;
reveals aparecem imediatamente;
delays são removidos;
transforms decorativos são reduzidos;
transições são minimizadas.

O movimento nunca é requisito para compreender ou utilizar a aplicação.
